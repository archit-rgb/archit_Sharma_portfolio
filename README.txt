ARCHIT SHARMA — PORTFOLIO WEBSITE
=================================

Files
-----
- index.html: complete responsive portfolio website (HTML + CSS in one file)
- README.txt: these publishing instructions

PREVIEW
-------
Open index.html in a modern browser to preview the website locally.

PUBLISH OPTION 1: GITHUB PAGES (free static hosting)
----------------------------------------------------
1. Sign in to GitHub or create an account.
2. Create a new public repository named: archit-sharma-portfolio
3. Upload index.html to the repository root (not inside another folder).
4. Open the repository's Settings > Pages.
5. Under the build/deployment section, choose deployment from a branch.
6. Select the main branch and /(root), then save.
7. Wait for GitHub Pages to publish. The website URL will be shown in Settings > Pages.
8. Open the published URL in a private/incognito window to test it.
9. Add the live URL to your LinkedIn Contact Info and resume.

PUBLISH OPTION 2: NETLIFY (simple drag-and-drop)
------------------------------------------------
1. Sign in to Netlify.
2. Create a new site using its manual deploy / drag-and-drop option.
3. Upload the index.html file or a folder containing it, following the current Netlify UI.
4. Wait for deployment and test the generated URL.
5. You can configure a custom domain later if desired.

BEFORE PUBLISHING
-----------------
- Review your phone number, email, LinkedIn URL, job titles and employment dates.
- The site uses summaries based on your supplied resume. Verify all claims and dates.
- The resume lists Jenkins pipeline work with a 50% deployment-time reduction; be ready to explain how it was measured.
- Selected-work cards summarize work areas, not separately verified client case studies.
- Do not add client IP addresses, internal network diagrams, passwords, security details, or confidential screenshots.
- For a more private portfolio, remove the phone number and use only the contact email or LinkedIn link.

This package does not publish the website automatically. You must sign in to your hosting provider and perform the upload/publish steps. No account credentials are included.
