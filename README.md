# Archit Sharma — Portfolio

A responsive single-page portfolio built with plain HTML, CSS, and JavaScript. No build tools or dependencies are required.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository. For a personal site, use `YOUR-USERNAME.github.io`; otherwise any repository name works.
2. Upload `index.html` and `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`, then save.
6. Wait for the Pages deployment to finish. Your site URL will be shown in the Pages settings.

## Before publishing
- Confirm role dates, client names, certifications, and all quantified achievements.
- The CI/CD pipeline on this site is an illustrative browser demo, not a real CI runner.
- Replace project descriptions with links to repositories or evidence as you publish real implementations.
- Update the email and LinkedIn URLs if they change.
